## Project Overview

This is an Atlassian Forge app for Jira Cloud that adds a custom project page. The architecture combines:
- **Frontend**: Vite + React custom UI (built as static assets)
- **Backend**: Forge resolver function (Node.js 20.x runtime)
- **Bridge**: `@forge/bridge` connects the React UI to backend resolvers

The app is registered at `app.id: ari:cloud:ecosystem::app/75403e69-092d-4ed1-a68c-ea312f1601e4` in the Jira workspace.

## Architecture

### Build Pipeline
1. Vite builds the React app from `ui/` into `static/ui/`
2. Forge packages `static/ui/` as a static resource
3. The Jira project page module loads the static UI and connects it to the resolver

### Key Locations
- **Frontend source**: `DEE-Demo/ui/src/` (App.jsx, main.jsx)
- **Backend resolver**: `DEE-Demo/backend/resolvers.js` - exports `handler` function
- **Build output**: `DEE-Demo/static/ui/` (gitignored, generated by Vite)
- **Manifest**: `DEE-Demo/manifest.yml` - defines modules, resources, and permissions
- **Vite config**: `DEE-Demo/vite.config.js` - sets root to `ui/`, outDir to `static/ui/`

### Communication Pattern
The frontend uses `invoke('main-resolver', { path: '/ping' })` from `@forge/bridge` to call the backend resolver defined in manifest.yml. The resolver receives requests with a `path` parameter and returns JSON responses.

## Development Workflow

All commands should be run from the `DEE-Demo/` directory.

### Initial Setup
```bash
cd DEE-Demo
npm install
```

### Build and Deploy Sequence
1. Build the UI:
   ```bash
   npm run build
   ```
   This creates `static/ui/` which Forge will serve.

2. Lint, deploy, and install to Jira:
   ```bash
   forge lint && forge deploy && forge install --upgrade --site https://YOUR-SITE.atlassian.net --product jira
   ```

### Local Development
For live development with hot reload:
```bash
forge tunnel
```

For UI-only development (disconnected from Forge):
```bash
npm run dev      # Vite dev server at localhost:5173
npm run preview  # Preview built UI locally
```

## Forge-Specific Notes

- Runtime is `nodejs20.x` (set in manifest.yml)
- The app uses `storage:app` permission scope
- The UI is served from `static/ui` as defined in the `resources` section
- The `jira:projectPage` module connects to the `main-resolver` function
- **Never commit the built `static/ui/` directory** - it's gitignored
- **Do not commit secret values** - keep sensitive data out of the repository
